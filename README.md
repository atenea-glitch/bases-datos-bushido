# Base de Datos para Tienda Online

Diseñar e implementar una base de datos relacional para la tienda online de una escuela, permitiendo gestionar los pedidos de material del alumnado.

## Tareas a Realizar

1. **Análisis de Requisitos:**
   - Identificar las entidades principales del negocio: Productos, Clientes, Pedidos y Detalles de Pedidos.
   - Definir los atributos necesarios para cada entidad (como ID, nombre, descripción, precio y stock en productos).

2. **Diseño del Esquema:**
   - Aplicar conceptos de normalización para reducir la redundancia y evitar anomalías.
   - Definir correctamente las claves primarias y foráneas para establecer las relaciones entre las tablas.

3. **Definición de Relaciones:**
   - Establecer relaciones entre entidades, por ejemplo, una relación de uno a muchos entre Clientes y Pedidos.
   - Opcionalmente, realizar un diagrama Entidad-Relación (ER) para visualizar la estructura.

4. **Instrucciones SQL:**
   - Escribir el código SQL necesario para crear la base de datos, las tablas y las relaciones.
   - Incluir restricciones de integridad como claves primarias, claves foráneas, UNIQUE y CHECK.

## Entregables para el Porfolio
- Un archivo `.sql` que contenga todas las instrucciones ejecutables para crear la estructura de la base de datos.
- Opcionalmente, el diagrama Entidad-Relación en formato PDF o imagen.
